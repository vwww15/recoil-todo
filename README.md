
# Todo-додаток на Recoil

Лабораторна робота з теми «Recoil — управління станом у React».

## Мета роботи

Навчитися використовувати Recoil для керування глобальним станом React-застосунку, створювати atom і selector та забезпечувати взаємодію компонентів без props drilling.

## Використані технології

- React 18
- Vite
- JavaScript
- Recoil
- CSS
- localStorage

## Реалізована функціональність

### Основні завдання

- Створено atom `todoListState` для зберігання задач.
- Реалізовано форму додавання нових задач.
- Додано список задач із чекбоксами.
- Створено selector `incompleteCount` для підрахунку невиконаних задач.

### Додаткові завдання

- Видалення окремих задач.
- Очищення всіх виконаних задач.
- Фільтрація: Всі / Активні / Виконані.
- Використання `selectorFamily`.
- Збереження задач у localStorage.
- Відновлення списку після перезавантаження сторінки.

## Структура проєкту

- `src/atoms.js` — глобальний стан задач.
- `src/selectors.js` — обчислення та фільтрація.
- `src/AddTodo.jsx` — додавання задач.
- `src/TodoList.jsx` — список задач.
- `src/App.jsx` — головний компонент.
- `src/index.css` — стилізація.

## Запуск проєкту

Встановлення залежностей:

```bash
npm install
```

Запуск локального сервера:

```bash
npm run dev
```

Створення production-збірки:

```bash
npm run build
```

## Результат

Створено інтерактивний Todo-додаток із глобальним станом на Recoil.

Виконано всі основні та додаткові завдання лабораторної роботи. Production-збірка успішна.

## Висновок

У ході лабораторної роботи закріплено навички роботи з Recoil у React. Створено глобальний стан за допомогою atom, реалізовано selector для обчислення похідних даних та selectorFamily для фільтрації задач.

Також реалізовано додавання, редагування статусу виконання, видалення та збереження задач у localStorage.
